# ChainProxy 链式代理

> 让浏览器**按需**走住宅 IP，而不用常开住宅代理。
>
> 前置代理 = 你本地的主流客户端（`127.0.0.1:10808`，mixed 协议）；
> 住宅代理 = 你的住宅 IP 服务商（SOCKS5 / HTTP / WireGuard）。
> ChainProxy 把两者串成一条链，给你开出**多个独立的本地端口**，
> 浏览器/软件只要指定其中某个端口，流量就是 `本地 →主流客户端→ 住宅 IP → 目标网站`。

---

## 为什么需要它

日常上网不需要住宅 IP，住宅 IP 又慢又贵；只有少数 ip 敏感的网站才必须用。
但主流客户端一次只能用一个出站，不能"平时走机房 IP、需要时才切住宅"。

而国内网络环境下，住宅 IP 往往**不能直连**，必须先经过一个非大陆 IP 的前置节点 ——
这就是"链式代理 / 前置代理"。

ChainProxy 做的事：**把前置和住宅拆开，各自绑定一个本地端口**，让你按需选用。
不用的端口不占流量，不开 ChainProxy 就完全不影响正常上网。

---

## 快速开始

1. 启动主流客户端，确认 `127.0.0.1:10808` 可用。
2. 运行 `dist\chainproxy.exe`。
3. 界面里：
   - **前置代理**：类型 `socks5`，地址 `127.0.0.1`，端口 `10808`；
   - **住宅代理**：点「添加」，类型选 `socks5`，填 `用户名:密码@主机:端口`（或分开填），设置本地端口例如 `10810`；
   - 点「保存并启动」。
4. 点「一键测试」，确认「前置出口 IP」与「链路出口 IP」**不同**即成功。
5. 浏览器/软件里把代理设为 `127.0.0.1:10810`。

支持 `user:pass@host:port` 一行粘贴，程序会自动拆分。

---

## 功能

- **前置代理设置**：socks5 / http / 直连三种类型，地址默认 `127.0.0.1`、端口默认 `10808`，可选用户名密码。
- **住宅代理**：
  - 类型 `socks5`、`http`、`wireguard`；
  - **可以添加多个**，每个绑定一个**独立本地端口**；
  - 端口全局唯一，启动前自动校验占用与冲突；
  - 支持 `user:pass@host:port` 格式一键导入。
- **本地端口协议**：mixed —— **同时接受 HTTP 代理与 SOCKS5 客户端**，省事。
- **状态展示**：每个上游一行，实时显示 `运行中 / 已停止 / 端口被占用 / 配置错误` 及原因。
- **主开关**：一键启停所有链；停止时释放全部端口与连接。
- **一键测试**：分层测试前置、逐条测试链路，直观给出两个出口 IP 与延迟。
- **不注册自启动**：程序不写注册表、不建计划任务、不装服务。

---

## 端口生命周期

| 时机 | 行为 |
|---|---|
| 程序启动 | 自动占用所有已启用上游的端口（可在设置里关闭） |
| 关掉主开关 / 退出程序 | 立即释放全部端口，并断开所有进行中的连接 |
| 端口被别的程序占用 | 该条上游标记为错误并提示是哪个端口，其它上游照常工作 |
| 程序崩溃 | 监听端口由操作系统自动回收 |

## 构建

```powershell
.\scripts\build.ps1
```

所有 Go 模块缓存 / 编译缓存都被重定向到 `F:\chain_proxy\.cache\`，
**不会在 `C:\Users\...\go` 或任何项目目录之外的位置写入任何文件**。
构建产物：`dist\chainproxy.exe`（单个静态可执行文件，无需安装运行时）。

---

## 命令行（可选，用于排障）

```powershell
chainproxy.exe test              # 用当前配置跑一遍分层测试
chainproxy.exe run               # 只跑核心服务（不开 GUI）
chainproxy.exe test --port 10810 # 指定本地端口测试
chainproxy.exe validate          # 只校验配置与端口
```
